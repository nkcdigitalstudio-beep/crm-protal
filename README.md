# Kavya Groups Tools CRM — interactive demo

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use Live Server.
3. Plain HTML, CSS and JavaScript; no build step required.

## Demo features
Dashboard reports; employee attendance edit/details and a 12-month calendar; customer edit/view/search/filter; app, website and executive enquiries with request status and email links; property inventory with India state and international country choices; notifications; expense folders; global search; light/dark themes.

## Important
This is a front-end demo. Sample data is held in JavaScript memory and resets on refresh. Email links open the user's mail application; there is no connected mail service, database, authentication, or live reporting backend. Add a backend before using real customer or employee data.
